# V1 Quality Audit Summary

## Executive result

V1 的本地生产构建在 18 条基线路由、360/390/768/1024/1440 五档宽度和全部既有交互状态下整体稳定；`npm run check` 通过 25 个测试文件 / 115 项 Vitest，Playwright 16/16 通过。审计确认 31 个需要进入修复发布的稳定 finding ID：3 个代码/逻辑问题、25 个内容问题、3 个视觉/页面问题。它们归并为 9 个修复任务，另设 1 个全量发布任务。

没有发现站点不可用、危险执行、主导航不可访问或已证实的虚假活动成果，因此 Critical 为零。优先级最高的是 GitHub Pages 新鲜上下文深链启动（CL-001、VP-001）、已发布但证据不足或与权威来源冲突的史实表述、人物生卒年和正式科学家精神标题，以及小字号索引文本的 WCAG AA 对比度。

## Critical findings

None observed.

## Important findings

- CL-001、VP-001：Pages 404 回退依赖 `sessionStorage`，存储拒绝时会中断跳转；正常存储场景下，浏览器路由器又在恢复历史地址之前构造，导致线上人物、图谱、影音和未知路径的新鲜深链保留 URL 却渲染首页。两项共享一个启动顺序与存储异常边界。
- CF-005、CF-007：钱伟长获奖年份存在权威来源冲突，返国航程细节缺少直接支持；应删除具体获奖年份和“从洛杉矶乘船”。
- CF-010、CF-012、CF-013、CF-016、CF-050：李三立生卒年需改为“1935—2022”；911 机章节与 1964 年 3 月节点缺少原始/官方档案，应删除；724 机与故事需收窄；首页不得再把全部节点称为“已核实”。
- CF-018、CF-020、CF-022、CF-023：黄宏嘉生卒年需改为“1924—2021”；《微波原理》具体出版年份有权威来源冲突，应改为“20世纪60年代”；煤气灶细节和“黄氏波片”章节缺少直接证据，应分别收窄和删除。
- CF-026、CF-028、CF-029、CF-032、CF-034、CF-036、CF-039、CF-040：孙晋良、杨雄里、谢少荣、岳晓冬的人物年份、摘要、领域或精神关系需依据官方页面修正；无具体事迹支持的精神关系应暂时移除。
- CF-041：六个精神主题标题需使用中央文件公布的完整规范表述，同时保持六个稳定 ID 不变。
- CF-043、CF-044、CF-045、CF-046、CF-048：四项 2026 年 7 月计划已过原定时间且没有完成证据；应改为“时间待重新确认”，保持 `planned` 和参与人数 0，并删除不存在、未登记的活动图片路径及来源 ID。
- VP-002：首页、核心人物、精神足迹和关于页的 14–16px 铜色索引文字仅约 3.03:1，未达到普通文字 4.5:1。

## Minor findings

- CL-002、CL-003：`motion` 无运行时导入；项目仅直接使用 `@playwright/test`，根级 `playwright` 声明重复。两项可以在不重构现有动效或 E2E 的情况下移除。
- VP-003：关于页“项目定位”12px 标签被高特异性规则覆盖成红底黑面组合，对比度约 2.02:1；应以专用类稳定使用现有浅色档案色。

## Verified areas with no defect observed

- 基线依赖安装、内容校验、ESLint、TypeScript、115 项 Vitest、生产构建和 16 项 Playwright 均通过；依赖审计为 0 个漏洞。
- 本地 18 条路由在五档宽度下没有横向溢出、控件裁切、缺失 H1、同源失败请求、控制台错误或页面错误。
- 移动导航、筛选与浏览器 Back、精神主题状态、图谱图形/列表模式、八人物/六主题关系、原生档案弹窗、图片失败降级和 reduced-motion 最终状态均通过。
- Pages 资源 base、Open Graph 资源、内部链接、HTTPS 媒体外链边界、监听器/观察器/动画帧清理、未知人物和本地全局 404 均有有效测试保护。
- 内容审计的 Verified 行不进入生产修改：CF-001、CF-003、CF-004、CF-006、CF-008、CF-009、CF-011、CF-014、CF-015、CF-017、CF-019、CF-021、CF-024、CF-025、CF-027、CF-030、CF-031、CF-033、CF-035、CF-037、CF-038、CF-042、CF-047、CF-049、CF-051。
- 用户提供的首页图谱断线截图对应旧版本；当前本地与线上 SVG 的三条边均在 `0 0 640 384` 视框内连接到人物、事件和精神节点，`outsideLines=0`。该截图已解决，不属于本轮 remediation；若再次出现，只重新采集 URL、硬刷新结果、JS/CSS 资源哈希和浏览器缩放证据。
